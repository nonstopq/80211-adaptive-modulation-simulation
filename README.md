# 802.11 Adaptive Modulation and SER Evaluation
This repository contains a MATLAB simulation evaluating the physical layer (PHY) performance of 802.11 wireless networks. The project models the Log-Distance Path Loss, Signal-to-Noise Ratio (SNR), and theoretical Symbol Error Rate (SER) across 2.4 GHz and 5 GHz frequency bands in an indoor environment.

## Files Included
* `wifi_evaluation.m`: MATLAB script that generates the environmental simulation, calculates the AWGN channel probabilities, and triggers the Adaptive Modulation and Coding (AMC) downshifts.
* `Project Performance Evaluation WiFi.pdf`: The full report with analysis of the physical layer behaviors and system trade-offs.
* `wifi_evaluation_results.png`: The visual graphs demonstrating the modulation downshifts.

## How to Run
To test this simulation, open `wifi_evaluation.m` in standard Base MATLAB (no specialized toolboxes required) and click Run.
